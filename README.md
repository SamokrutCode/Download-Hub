# ⛋ Download Hub

![UI Preview](https://img.shields.io/badge/UI-Glassmorphism-black?style=for-the-badge&logo=css3)
![No Backend](https://img.shields.io/badge/Backend-None-red?style=for-the-badge)
![Storage](https://img.shields.io/badge/Storage-LocalStorage-blue?style=for-the-badge)

**Download Hub** — это стильный, быстрый и полностью автономный портал для хранения ссылок и файлов. 
Проект выполнен в виде Single Page Application (SPA) и не требует подключения к серверу или базе данных. Все данные, включая аккаунты пользователей и контент, надежно хранятся прямо в вашем браузере (через localStorage).

Дизайн вдохновлен эстетикой **Dark Glassmorphism** (тёмное матовое стекло) и **Neumorphism** с плавными анимациями, неоновыми бликами и строгими минималистичными иконками.

---

## ✨ Ключевые возможности

### 🔒 Система авторизации (Role-Based Access)
Встроенная frontend-система ролей для управления доступом:
- **Guest (Гость):** Может только просматривать каталог.
- **User (Пользователь):** Может скачивать файлы и добавлять в избранное.
- **VIP:** Имеет доступ к эксклюзивному контенту (отмеченному звездочкой ★ VIP).
- **Admin (Администратор):** Полный контроль над приложением. Управление пользователями, добавление и редактирование контента.

### 👤 Личный кабинет
- Просмотр своей текущей роли.
- Изменение пароля.
- **Моё избранное:** Удобный список сохраненных программ и полезных ссылок, которые вы отметили звездочкой (★).

### ⚙️ Админ-панель
- Удобная таблица для управления пользователями прямо из личного кабинета.
- Смена ролей пользователям в один клик.
- Удаление аккаунтов.
- Добавление, редактирование и удаление карточек с загрузками и полезными ссылками.
- Управление категориями.

### 📦 Управление контентом
- **Две независимые вкладки:** "Загрузки" (файлы) и "Полезные ссылки".
- Встроенный выбор минималистичных иконок для карточек.
- Живой поиск по названию и описанию.
- Система тегов (размер файла, категория, VIP-статус).
- **Импорт / Экспорт:** Возможность выгрузить всю базу данных сайта (в формате .json) и загрузить её на другом устройстве.

## 🎨 Дизайн и UI
- **Dark Glassmorphism:** Современные панели и кнопки из темного матового стекла.
- **Иконки:** Светлые неоморфные стеклянные "кубики" с контрастными монохромными символами.
- Всплывающие Toast-уведомления (успех/ошибка).
- Плавные анимации появления карточек (Staggered fade-in).
- Полная адаптивность под любые экраны.

---

## 🚀 Как запустить

Поскольку проект не имеет бэкенда, его запуск занимает ровно одну секунду:

1. Скачайте репозиторий.
2. Откройте файл index.html в любом современном браузере.
3. Готово!



*(Вы всегда можете зарегистрировать новый аккаунт на главной странице).*

## 🛠 Технологии
- **HTML5** (Семантическая разметка)
- **CSS3** (Flexbox, Grid, CSS Variables, Backdrop-filter, Animations)
- **Vanilla JavaScript** (ES6+, DOM Manipulation)
